# 界面布局草图

参考 Elecard StreamEye：分析控制窗在前，解码预览窗独立在后（或并排）。

## 交互要点

1. **条带点击** → 当前帧变更 → 信息面板 + 预览同步。
2. **拖拽文件** → 控制窗或预览窗均可接受；加载后重置到第 0 帧。
3. **播放** → 定时器按帧率（若可知）或固定间隔推进；暂停停止定时器。
4. **两窗独立** → 普通 `QMainWindow`/`QWidget`，无 MDI 强制停靠。

## 颜色与性能

- 条带颜色见架构文档；选中帧加 2px 高对比描边。
- 仅绘制视口内条带；缩放时调整 `pixelsPerFrame`（默认 ≥ 2px）。
